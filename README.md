# From Scribbles to Reliable Masks

Official implementation of:

**From Scribbles to Reliable Masks: Uncertainty-Guided Weak Supervision for Chest CT Lung Lesion Segmentation**

## Project Goal

This repository provides a reproducible Kaggle-based implementation for weakly supervised chest CT lung lesion segmentation using sparse scribble annotations, uncertainty-guided pseudo-label refinement, and publication-quality evaluation.

## Core Components

- Chest CT preprocessing
- Scribble generation from full masks
- Weakly supervised segmentation
- Uncertainty estimation
- Confidence-guided pseudo-label refinement
- Ablation studies
- Publication-quality figures and tables
